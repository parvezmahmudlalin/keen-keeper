Project Name: Keen Keeper

Description: Keen Keeper is a React-based web app to track and manage interactions like Calls, Texts, and Videos with a visual dashboard.

Technologies Used----

- React.js  
- React Router  
- Context API  
- Recharts  
- Tailwind CSS  


 Key Features-----

-  Track Call, Text, and Video activities  
-  Visual statistics with Pie Chart  
-  Fully responsive design
